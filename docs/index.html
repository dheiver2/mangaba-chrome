01

Features

Everything the extension does, in a single panel next to your browsing.

Chat with the page

Reads the content of the active tab and answers questions about it, with Markdown replies and real-time streaming.

Agent mode

A team of agents runs real tasks in the browser: navigating, clicking, typing, scrolling and reading, deciding step by step.

Forms

Maps fields and options, fills them in batches, validates with the site itself and never invents personal data.

Web research

Checks several sources, cross-references the information and answers citing the domains used.

Social networks

Reads the inbox and direct messages, drafts replies and likes. Nothing is published without your confirmation.

Visual analysis

Captures the screen and describes it with a vision model when the page text is not enough.

02

Agent team

Each agent has a clear role. Agent mode chooses which to use at each step of the task.

Agent 01Navigation

Opens pages, clicks and moves through sites.

Agent 02Research

Searches different sources and checks the data.

Agent 03Reading

Extracts the relevant content of a page.

Agent 04Forms

Fills in fields from your data.

Agent 05Social networks

Reads messages and prepares replies for you to review.

Agent 06Access

Takes you to the login screen without touching your password.

03

Privacy and security

Designed so you stay in control of every action.

PasswordsThe extension never types your password. It fills in the username and you complete the login.
ConfirmationSensitive actions require your approval before they run.
My dataValues stay out of the model. The agent only sees the field names and the value is placed directly on the page.
Prompt injectionMalicious content from pages is treated as data, not as instructions.
ContentHTML is escaped to prevent XSS, and the extension code is open and auditable.
04

Installation

Takes about two minutes. The extension is loaded manually, like any developer package.

  1. Download the version 2.17.1 ZIP file and unzip it into a folder.
  2. Open chrome://extensions in Chrome or Edge.
  3. Turn on Developer mode, in the top right corner.
  4. Click Load unpacked and select the unzipped folder.
  5. Click the Mangaba icon to open the side panel and sign in or create an account. An account is required.
  6. On the next screen, paste your Mangaba Router key and click Validate and continue. If you do not have one yet, create one in the Mangaba Router console.
Already on 2.16.0? After updating, the panel asks you to sign in or create an account. The key you already had is reused by the first account that signs in on this browser.
Before you start: agent mode depends on a model with good reasoning ability. Smaller models tend to make more mistakes in the steps.
